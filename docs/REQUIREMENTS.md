# Requirements

## Functional requirements

- User registration and login.
- Role-based access for ADMIN, CUSTOMER, and MARKETING_MANAGER.
- Category and product management.
- Inventory validation during order placement.
- Payment processing for orders.
- Marketing promotions and campaign management.
- Notifications and audit logs.
- Dashboard summary endpoint.

## Non-functional requirements

- Secure authentication with JWT.
- Transactional order handling.
- Data persistence using PostgreSQL.
- Flyway schema versioning.
- API documentation via Swagger UI.
- Test coverage for core business logic.
